ไฟล์ Excel ต้นฉบับทุกครั้งที่อัปโหลด เก็บในโฟลเดอร์ย่อย **สต๊อกเจสตาร์ ไฟล์ต้นฉบับ** (ระบบสร้างเอง)

## สิทธิ์ (จำกัดด้วย LINE userId)
- ใครเปิดหน้าครั้งแรก → ถูกเพิ่มในแท็บ **ผู้ใช้** เป็น `รออนุมัติ` อัตโนมัติ และเห็นหน้า "ยังไม่ได้รับสิทธิ์"
- เจ้าของเปิดชีท → แก้คอลัมน์ C เป็น `อัปโหลด` (ค้นหา + อัปโหลด) หรือ `ดู` (ค้นหาอย่างเดียว) → ให้คนนั้นเปิดหน้าใหม่
- ถอนสิทธิ์ = แก้เป็น `ปิด`
- หลังบ้านตรวจ ID token กับ LINE ทุกคำขอ ซ่อนปุ่มอย่างเดียวไม่พอ — ยิงตรงโดยไม่มีสิทธิ์ถูกปฏิเสธ
- เริ่มต้น: Thipwon + คุณอ้อย = `อัปโหลด`

## ใช้งาน
1. มือถือ: ริชเมนู → **เช็คสต๊อก** · คอม: เปิด `https://liff.line.me/2012109669-qQAVcyBR` ในเบราว์เซอร์ → login LINE (LINE บนคอมไม่แสดงริชเมนู)
2. กล่องบนสุดบอกชื่อไฟล์ + วันเวลา + ผู้อัปโหลด — **เขียว** = อัปเดตวันนี้ · **เหลือง** = ยังไม่ได้อัปเดตวันนี้ · **แดง** = ยังไม่มีไฟล์
3. ค้นหา — ล้อ: ขอบ / PCD / ET / สี (ไทยหรืออังกฤษ) / รุ่น / รหัส เช่น `18 6/139.7 ดำ ด้าน` · ยาง: ขนาด / ขอบ / ยี่ห้อ / รุ่น / ปี เช่น `265/65 17 bridgestone`
4. อัปโหลด (เฉพาะสิทธิ์ `อัปโหลด`): กด **อัปเดตไฟล์วันนี้** (คอมลากไฟล์วางได้) → ตรวจตารางเทียบไฟล์เดิม → **บันทึกให้ทุกคน**
   - เลือกปุ่ม ล้อแม็ก / ยาง ให้ตรงกับไฟล์ก่อนอัปโหลด — ใส่ไฟล์ผิดชุดระบบไม่รับ (ไฟล์ล้อมีชีทชื่อ "ขอบ.." ไฟล์ยางไม่มี)
   - ไม่รับ: ไม่ใช่ .xlsx/.xls, ไม่มีชีทที่มีหัว "รหัส" + "ชื่อ", น้อยกว่า 50 รายการ
   - ต้องติ๊กยืนยันก่อน: วันที่ในชื่อไฟล์เก่ากว่าไฟล์ปัจจุบัน, ชื่อไฟล์ซ้ำ, รายการหายเกิน 20%, ชื่อสาขาเปลี่ยน
   - ผลสำเร็จ/ไม่สำเร็จค้างบนจอจนกด × · ไม่สำเร็จ = ข้อมูลเดิมยังอยู่

## แก้ไข / อัปเดต
- หน้าเว็บ: แก้ `stock/index.html` (bump `PAGE_VERSION`) → push → รอ 1–2 นาที
- หลังบ้าน: แก้ `Code.gs` ใน Apps Script → **Deploy → Manage deployments → ✏️ → New version → Deploy** (URL เดิม)
- รูปแบบไฟล์ที่อ่านได้ (ทั้ง 2 ชุด ใช้ `parseSheets`): ทุกชีทที่แถวแรกมีหัว `รหัส` ตามด้วย `ชื่อ` แล้วเป็นชื่อสาขา · อ่านตาม**ชื่อหัวคอลัมน์** ไม่ยึดตำแหน่ง (ชีทยางบางยี่ห้อสาขาไม่ครบ / GOODYEAR มีคอลัมน์รหัสซ้ำ 2 ช่อง) สาขาที่ชีทนั้นไม่มี = 0 · ชีทว่าง (Sheet1/Sheet3) ถูกข้าม
  - ล้อ: กลุ่ม (ชิป) = ตัวเลขในชื่อชีท `ขอบ18` → 18
  - ยาง: 1 ชีท = 1 ยี่ห้อ · กลุ่ม = ขอบจากชื่อสินค้า `… R17 …` → 17 (ไม่เจอ → "อื่นๆ")
- เพิ่มชุดข้อมูลใหม่: เพิ่มบรรทัดใน `KINDS` (index.html) + `KIND_TAB` (Code.gs) + สร้างแท็บในชีท

## ความเร็วตอนเปิดหน้า (24 พ.ย. 2026, PAGE_VERSION 2026-11-24e / Apps Script Version 2)
- หน้าเรียกหลังบ้าน **ครั้งเดียว** (`data` ตรวจสิทธิ์ + ส่งข้อมูล + ข้อมูลผู้ใช้ `me`) ไม่มี `whoami` แยกแล้ว
- เครื่องผู้ใช้ **จำข้อมูลชุดล่าสุด** ไว้ใน localStorage (แยกตาม LINE userId + ชุด) → เปิดครั้งถัดไปเห็นทันที แล้วเช็คกับหลังบ้านตามหลัง ("กำลังเช็คข้อมูลล่าสุด…")
  - หลังบ้านส่ง `ver` (ลายนิ้วมือของสต๊อก + รูปสินค้า) · ถ้าตรงกับที่เครื่องจำไว้ ตอบ `same` ไม่ส่งข้อมูลซ้ำ
  - **หลังบ้านยังตรวจสิทธิ์ทุกครั้ง** — ถูกแก้เป็น `ปิด`/`รออนุมัติ` → เปิดครั้งถัดไปข้อมูลในเครื่องถูกล้างและขึ้นหน้าไม่มีสิทธิ์ (ช่วงสั้น ๆ ก่อนหลังบ้านตอบ จะยังเห็นข้อมูลชุดเก่าที่จำไว้)
  - เน็ตหลุด/หลังบ้านไม่ตอบ → แสดงข้อมูลที่จำไว้ พร้อมข้อความบอก
- หลังบ้านจำผลตรวจ ID token กับ LINE ไว้ใน CacheService ไม่เกิน 10 นาที (และไม่เกินอายุ token) — สิทธิ์ในแท็บ ผู้ใช้ อ่านสดทุกครั้ง ไม่ cache
- ตัวอ่าน Excel (xlsx ~900 KB) โหลดเฉพาะตอนกดอัปโหลด
