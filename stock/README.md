ไฟล์ Excel ต้นฉบับทุกครั้งที่อัปโหลด เก็บในโฟลเดอร์ย่อย **สต๊อกเจสตาร์ ไฟล์ต้นฉบับ** (ระบบสร้างเอง)

## สิทธิ์ (จำกัดด้วย LINE userId)
- ใครเปิดหน้าครั้งแรก → ถูกเพิ่มในแท็บ **ผู้ใช้** เป็น `รออนุมัติ` อัตโนมัติ และเห็นหน้า "ยังไม่ได้รับสิทธิ์"
- เจ้าของเปิดชีท → แก้คอลัมน์ C เป็น `อัปโหลด` (ค้นหา + อัปโหลด) หรือ `ดู` (ค้นหาอย่างเดียว) → ให้คนนั้นเปิดหน้าใหม่
- ถอนสิทธิ์ = แก้เป็น `ปิด`
- หลังบ้านตรวจ ID token กับ LINE ทุกคำขอ ซ่อนปุ่มอย่างเดียวไม่พอ — ยิงตรงโดยไม่มีสิทธิ์ถูกปฏิเสธ
- เริ่มต้น: Thipwon + คุณอ้อย = `อัปโหลด`

## ใช้งาน
1. มือถือ: ริชเมนู → **เช็คสต๊อก** · คอม: เปิด `https://liff.line.me/<LIFF ID>` ในเบราว์เซอร์ → login LINE (LINE บนคอมไม่แสดงริชเมนู)
2. กล่องบนสุดบอกชื่อไฟล์ + วันเวลา + ผู้อัปโหลด — **เขียว** = อัปเดตวันนี้ · **เหลือง** = ยังไม่ได้อัปเดตวันนี้ · **แดง** = ยังไม่มีไฟล์
3. ค้นหา: ขอบ / PCD / ET / สี (ไทยหรืออังกฤษ) / รุ่น / รหัส เช่น `18 6/139.7 ดำ ด้าน`
4. อัปโหลด (เฉพาะสิทธิ์ `อัปโหลด`): กด **อัปเดตไฟล์วันนี้** (คอมลากไฟล์วางได้) → ตรวจตารางเทียบไฟล์เดิม → **บันทึกให้ทุกคน**
   - ไม่รับ: ไม่ใช่ .xlsx/.xls, ไม่มีชีทที่ A1 = "รหัส", ชื่อสาขาแต่ละชีทไม่ตรงกัน, น้อยกว่า 50 รายการ
   - ต้องติ๊กยืนยันก่อน: วันที่ในชื่อไฟล์เก่ากว่าไฟล์ปัจจุบัน, ชื่อไฟล์ซ้ำ, รายการหายเกิน 20%, ชื่อสาขาเปลี่ยน
   - ผลสำเร็จ/ไม่สำเร็จค้างบนจอจนกด × · ไม่สำเร็จ = ข้อมูลเดิมยังอยู่

## ติดตั้งครั้งแรก
1. เปิดชีท **YANG Haus สต๊อกเจสตาร์** → ส่วนขยาย → Apps Script → วาง `Code.gs` ทั้งไฟล์ → บันทึก
2. Project Settings → Script properties → เพิ่ม `LINE_CHANNEL_ID` = Channel ID ของ "YH ขนส่ง Login" (ค่าเดียวกับระบบจดบัญชี)
3. รันฟังก์ชัน `testConfig` 1 ครั้ง (กดอนุญาตสิทธิ์ Sheet/Drive) → Log ต้องขึ้น มี ทุกตัว
4. Deploy → New deployment → Web app → Execute as **Me** / Who has access **Anyone** → คัดลอก Web app URL
5. developers.line.biz → Provider YangHaus → "YH ขนส่ง Login" → แท็บ LIFF → Add: Size **Full**, Endpoint URL = `https://thipwonh-ship-it.github.io/yanghaus-liff/stock/`, Scopes **openid + profile** → คัดลอก LIFF ID
6. ใส่ 2 ค่าใน `stock/index.html` (`LIFF_ID`, `GAS_URL`) → push
7. Thipwon + คุณอ้อย เปิดหน้า 1 ครั้ง → แก้สิทธิ์ในแท็บ ผู้ใช้ เป็น `อัปโหลด`
8. ริชเมนู: ดู [../richmenu/README.md](../richmenu/README.md)

## แก้ไข / อัปเดต
- หน้าเว็บ: แก้ `stock/index.html` (bump `PAGE_VERSION`) → push → รอ 1–2 นาที
- หลังบ้าน: แก้ `Code.gs` ใน Apps Script → **Deploy → Manage deployments → ✏️ → New version → Deploy** (URL เดิม)
- เพิ่มชุด **ยาง**: (1) เขียน `parseTire(wb)` ใน index.html ให้คืน `{branches, items:[[กลุ่ม, รหัส, ชื่อ, [จำนวนตามสาขา]]], sheets}` (2) เพิ่มบรรทัดใน `KINDS` — หลังบ้านกับแท็บ สต๊อกยาง พร้อมแล้ว
- ไฟล์ล้อ KAYS ที่อ่านได้: ทุกชีทที่ A1 = `รหัส` (คอลัมน์ รหัส | ชื่อ | สาขา…) ชื่อชีท `ขอบ18` → กลุ่ม 18 · ชีทอื่น (เช่น Sheet3) ถูกข้าม
