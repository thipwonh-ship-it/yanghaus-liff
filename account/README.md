## ติดตั้งครั้งแรก (ทำตามลำดับ)

### 1. Gemini API key (ฟรี ไม่ต้องผูกบัตร)

3. ห้ามวางคีย์ลงใน repo — ใส่ใน Apps Script ข้อ 2 เท่านั้น

### 2. Apps Script
1. เปิดชีท YANG Haus บัญชีซื้อ-ขาย 2026 → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิมในหน้า แล้ววาง `Code.gs` ทั้งไฟล์ → บันทึก (ตั้งชื่อโปรเจกต์ เช่น "จดบัญชี LINE")

   - Property: `GEMINI_API_KEY` Value: คีย์จากข้อ 1 → Save
4. ด้านบนเลือกฟังก์ชัน `testConfig` → **Run** → อนุญาตสิทธิ์ (Advanced → Go to … (unsafe) → Allow) → ดู Execution log ต้องเห็นรายการ ธุรกิจ/ประเภท
5. **Deploy → New deployment** → ⚙️ เลือก **Web app**
   - Execute as: **Me** / Who has access: **Anyone** → Deploy
6. copy **Web app URL** (ลงท้าย `/exec`)

## วิธีใช้
1. กดปุ่ม 🧾 จดบัญชี ในไลน์
2. เลือก **ค่าใช้จ่าย** / **ซื้อยาง/ล้อ** / **ส่ง COD** → ถ่ายรูปใบเสร็จ
3. รอ AI อ่าน 3–5 วิ → ตรวจยอด/วันที่/ติ๊ก "มีใบกำกับภาษี" → บันทึก
4. ได้ข้อความสรุปในแชท + ลิงก์รูป / กด "จดใบต่อไป" ได้เลย

กติกาที่ฝังไว้
- ค่าน้ำมัน → ติ๊ก "มีใบกำกับ" ออกอัตโนมัติ (เคลม VAT ไม่ได้)
- ช่อง "ซื้อจาก" (Shopee/TikTok/Lazada/Facebook/LINE/เว็บไซต์/หน้าร้าน/อื่นๆ จากแท็บ ตั้งค่า คอลัมน์ M) → ค่าใช้จ่าย!O / ซื้อ!P — แคปหน้าจอออเดอร์ออนไลน์ส่งได้ AI เดาแหล่งซื้อจาก UI และใช้เลขออเดอร์เป็นเลขที่อ้างอิง แต่ไม่ใช่ใบกำกับ (ไม่ติ๊ก VAT)
- รับ 4 แบบ: ใบกำกับภาษี / ใบเสร็จ / แคปหน้าจอออเดอร์ / สลิปโอน (กติกาของ Thipwon: มีใบเสร็จส่งใบเสร็จ ไม่มีส่งสลิปโอน) — สลิป: ผู้ขาย = ผู้รับโอน, เลขที่ = เลขอ้างอิงรายการ, ต้องกรอกรายละเอียดว่าซื้ออะไรเอง
- กันซ้ำ (ปฏิเสธเลย ไม่ถาม): เลขที่ใบกำกับซ้ำในแท็บใดก็ได้ หรือ วันที่+ผู้ขาย+ยอดเท่ากัน → แจ้งแถวที่ซ้ำ ไม่บันทึก ไม่เก็บรูป
- ไม่มี GEMINI_API_KEY / เกินโควตา → ยังใช้ได้ แค่กรอกเอง
- คอลัมน์สูตร (ฐานภาษี/VAT) ไม่ถูกเขียนทับ — ชีทคำนวณเอง → ขึ้นแท็บ **รายงานภาษีซื้อ** อัตโนมัติ

### 📦 ส่ง COD (ใบเสร็จ Flash / ใบปะหน้า NNP ฯลฯ)
1 ใบ → เขียน 3 ที่ ผูกกันด้วย **เลขพัสดุ**:
- แท็บ **COD** (ทะเบียนพัสดุ): วันที่ ขนส่ง เลขพัสดุ ลูกค้า ยอด COD ค่าส่ง COD fee VAT · ☐ **เงินเข้าแล้ว** + วันที่/ยอดที่โอนเข้า (คุณติ๊กเองเมื่อขนส่งโอน) · มุมขวาบนสรุป COD ค้างรับ
- แท็บ **ขาย**: แถวขาย ช่องทาง Facebook (หรือที่เลือก) เลขออเดอร์ = เลขพัสดุ ยอด = COD ไม่ออกใบกำกับ · ช่อง "ยอดเงินเข้าจริง" และ "รับเงินแล้ว" เป็นสูตรดึงจากแท็บ COD อัตโนมัติ
- แท็บ **ค่าใช้จ่าย**: ค่าส่ง+ธรรมเนียม ประเภท Lalamove/ค่าส่งสินค้า อ้างอิงเลขพัสดุ → ไปหักในกำไรต่อออเดอร์ (เฉพาะติ๊ก "จ่ายค่าส่งเงินสดต้นทาง" — ถ้าขนส่งหักจากยอด COD ไม่ลง จะไปสะท้อนที่ส่วนต่างตอนเงินเข้าแทน)
- Flash คิด COD fee 2.5% และ NNP 3% ของยอด COD (แก้อัตราที่ `COD_FEE_RATE` ใน index.html): Flash พิมพ์ fee ในใบแต่ไม่พิมพ์ยอด COD → ฟอร์มคำนวณยอด COD = fee ÷ 2.5% / NNP พิมพ์ยอด COD (`***3,090`) + ค่าส่ง 500 แต่เก็บ fee 3% สดนอกใบ → ฟอร์มคำนวณ fee = COD × 3% และลงค่าใช้จ่ายรวม (ค่าส่ง + fee)
- รายชื่อขนส่งแก้ที่แท็บ ตั้งค่า คอลัมน์ K
- กันซ้ำด้วยเลขพัสดุ

### 🧾 ขาย (โอน/ขายส่ง) — ขายที่ไม่ใช่ COD (Facebook / LINE / ขายส่ง)
ถ่ายสลิปที่ลูกค้าโอน หรือแคปแชทออเดอร์ → AI อ่านชื่อ เบอร์ จังหวัด สินค้า ยอด → แถวในแท็บ **ขาย** (D เลขอ้างอิง = ที่กรอก หรือระบบตั้ง FB-YYYYMMDD-001 / LN- / WS-; M = ยอดถ้าติ๊ก "รับเงินแล้ว"; S รับเงินแล้ว; U เบอร์ V จังหวัด) รูปเก็บใน ส่งบัญชี/YYYY-MM/ภาษีขาย · กันซ้ำด้วยเลขอ้างอิง หรือ วันที่+ลูกค้า+ยอด
COD ก็เก็บเบอร์/จังหวัดลง COD!S,T และ ขาย!U,V ด้วย

### 👥 แท็บ ลูกค้า (อัตโนมัติ ห้ามพิมพ์)
รวมจากแท็บขาย (เฉพาะธุรกิจ YANG Haus, ยอด > 0): key = เบอร์โทร (ถ้ามี) ไม่งั้นชื่อ (ขาย!W สูตรซ่อน) → ชื่อ เบอร์ จังหวัด ช่องทาง ซื้อกี่ครั้ง ครั้งแรก/ล่าสุด วันตั้งแต่ซื้อล่าสุด ยอดรวม สินค้าที่เคยซื้อ ติดต่อได้ · เรียงตามซื้อล่าสุด แถวเขียว = ซื้อซ้ำ · สรุปบนสุด: ลูกค้าทั้งหมด / ซื้อซ้ำ / มีเบอร์ / ไม่ได้ซื้อ >180 วัน
ลูกค้าแพลตฟอร์ม (Shopee/TikTok) เติมเดือนละครั้งวันที่ 7 จาก Order export (ชื่อผู้ใช้ จังหวัด สินค้า) ลงแท็บขาย

### 💰 เงิน COD เข้าแล้ว (ปุ่มในหน้าแรกของฟอร์ม)
**เฉพาะผู้ดูแล** (userId ใน Script property `COD_ADMINS`) — ปุ่มโผล่เฉพาะคนที่มีสิทธิ์ และหลังบ้านตรวจ ID token กับ LINE อีกชั้น ปลอมไม่ได้
ตั้งค่า: Apps Script → Script properties → `LINE_CHANNEL_ID` = Channel ID ของ channel "YH ขนส่ง Login" (developers.line.biz → channel → Basic settings) และ `COD_ADMINS` = userId คั่นด้วย , (ให้แต่ละคนเปิดหน้าฟอร์ม เลื่อนลงล่างสุด จะเห็น "LINE userId: U…")
แสดงพัสดุ COD ที่ยังไม่ติ๊กเงินเข้า (แท็บ COD คอลัมน์ L = FALSE) เรียงตามวันส่ง → ติ๊กชิ้นที่ขนส่งโอนแล้ว แก้ยอดได้ → บันทึก → เขียน L=TRUE, M วันที่, N ยอด (เช็คว่าเลขพัสดุตรงแถวก่อนเขียน) → แถวขายขึ้น "รับเงินแล้ว" เอง

## คอลัมน์ที่เขียน
- **ค่าใช้จ่าย**: A วันที่ B ธุรกิจ C ประเภท D รายละเอียด E ยอด F มีใบกำกับ · I ผู้ขาย J อ้างอิงออเดอร์ K หมายเหตุ L เลขที่ใบกำกับ M เลขผู้เสียภาษี N รูปใบเสร็จ O ซื้อจาก
- **COD**: A วันที่ส่ง B ขนส่ง C เลขพัสดุ D ลูกค้า E สินค้า F ยอด COD G ค่าส่ง H COD fee I VAT · J รวมจ่าย (สูตร) · K อ้างอิง L เงินเข้าแล้ว M วันที่เงินเข้า N ยอดโอนเข้า · O ส่วนต่าง (สูตร) · P รูป Q หมายเหตุ R ผู้บันทึก
- **ขาย** (จาก COD): A–I ค่า, M และ S เป็นสูตรรายแถวอ้างแท็บ COD, O = 0, T หมายเหตุ, U เบอร์, V จังหวัด; (จาก ขาย): A–I, L, M, O, S, T, U, V
- **COD**: เพิ่ม S เบอร์โทร T จังหวัด (สรุปย้ายไป W1:X5)
- **ซื้อ**: A วันที่ B ธุรกิจ C ซัพพลายเออร์ D สินค้า E จำนวน F ยอดรวม G มีใบกำกับ · J เลขที่ใบกำกับ K ขนส่งเข้า L อ้างอิงออเดอร์ M หมายเหตุ N รูปใบเสร็จ O เลขผู้เสียภาษี P ซื้อจาก

## แก้ไข / อัปเดต
- **แก้หน้าฟอร์ม** → แก้ `account/index.html` → upload ทับใน GitHub → รอ 1–2 นาที
- **แก้หลังบ้าน** → แก้ `Code.gs` ใน Apps Script → บันทึก → **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (ไม่ทำ = โค้ดเก่ายังทำงาน) URL เดิม
- **เปลี่ยนชีท/โฟลเดอร์** → แก้ `SHEET_ID` / `FOLDER_ID` บนสุดของ Code.gs → Deploy ใหม่
- **รุ่น AI** → `GEMINI_PREFER` บนสุดของ Code.gs คือลำดับที่อยากใช้ ระบบดึงรายชื่อรุ่นที่คีย์ใช้ได้จริงจาก Google (cache 6 ชม.) แล้วจับคู่ ถ้ารุ่นแรกล้น (503/429) ไปรุ่นถัดไปเอง รุ่นที่ใช้ได้ล่าสุดอยู่ใน Script property `GEMINI_MODEL_OK`
- รายการ dropdown (ธุรกิจ/ประเภท/ซัพพลายเออร์) ดึงจากแท็บ `ตั้งค่า` ของชีท แก้ที่ชีทได้เลย
