1. เปิดชีท YANG Haus บัญชีซื้อ-ขาย 2026 → เมนู **ส่วนขยาย → Apps Script**

### 🛞 ซื้อของมาขาย — ใบส่งของมาก่อน ใบกำกับตัวจริงมาทีหลัง
ซัพพลายเออร์ (เช่น ป.รุ่งโรจน์) ให้ใบส่งของ/สำเนาใบกำกับตอนรับของ แล้วส่งต้นฉบับใบกำกับตามมา → ฟอร์มมีตัวเลือก "เอกสารที่ได้ตอนนี้": **ใบส่งของ/สำเนา** (ลงต้นทุน+VAT ปกติ แต่ ซื้อ!Q = FALSE แถวสีส้ม "รอใบกำกับตัวจริง") / **ใบกำกับตัวจริง** (ถ้าเลขที่เดิมมีแล้ว → ไม่ลงซ้ำ ติ๊ก Q = TRUE + เก็บรูปตัวจริงใน ภาษีซื้อ) · รายงานภาษีซื้อ D4 นับ "รอใบกำกับตัวจริง" ของเดือนนั้น — ก่อนยื่น ภ.พ.30 ต้องเป็น 0
- **JSM/เจสตาร์ (ใบกำกับรวบหลายใบส่งของ รายการไม่ตรงแต่ยอดตรง)**: ถ่ายใบกำกับด้วย "ใบกำกับตัวจริง" → ถ้าเลขที่ไม่เคยมี ฟอร์มขึ้นรายการใบส่งของที่ค้าง (ซัพพลายเออร์เดียวกันติ๊กให้ก่อน) → ติ๊กให้ยอดรวม = ยอดใบกำกับ → บันทึก = ใส่เลขใบกำกับ/เลขผู้เสียภาษี/วันที่ใบกำกับ ให้ทุกแถว + Q = TRUE + หมายเหตุเก็บเลขใบส่งของเดิม (action `buyPending` / `buyMatch`) · รายงานภาษีซื้อรวมแถวที่เลขใบกำกับเดียวกันเป็น 1 บรรทัด

### 📦 ส่ง COD (ใบปะหน้า + ใบเสร็จขนส่ง)
ถ่าย **2 รูป**: รูปที่ 1 ใบปะหน้า (ชื่อ เบอร์ จังหวัด เลขพัสดุ ยอด COD) + รูปที่ 2 ใบเสร็จขนส่ง (ค่าส่ง fee VAT เลขที่ใบเสร็จ — ใบเสร็จ Flash ไม่มีข้อมูลลูกค้า) AI อ่านทั้งสองรูป รูปที่ 2 เติมเฉพาะช่องว่าง · เก็บทั้ง 2 รูป (ชื่อไฟล์ _ใบปะหน้า / _ใบเสร็จขนส่ง) ลิงก์คั่นด้วย | ใน COD!P · ชื่อลูกค้าที่เป็น Cash/เงินสด/โอน ถูกกรองทิ้ง
1 รายการ → เขียน 3 ที่ ผูกกันด้วย **เลขพัสดุ**:
- แท็บ **COD** (ทะเบียนพัสดุ): วันที่ ขนส่ง เลขพัสดุ ลูกค้า ยอด COD ค่าส่ง COD fee VAT · ☐ **เงินเข้าแล้ว** + วันที่/ยอดที่โอนเข้า (คุณติ๊กเองเมื่อขนส่งโอน) · มุมขวาบนสรุป COD ค้างรับ
- แท็บ **ขาย**: แถวขาย ช่องทาง Facebook (หรือที่เลือก) เลขออเดอร์ = เลขพัสดุ ยอด = COD ไม่ออกใบกำกับ · ช่อง "ยอดเงินเข้าจริง" และ "รับเงินแล้ว" เป็นสูตรดึงจากแท็บ COD อัตโนมัติ
- แท็บ **ค่าใช้จ่าย**: ค่าส่ง+ธรรมเนียม ประเภท Lalamove/ค่าส่งสินค้า อ้างอิงเลขพัสดุ → ไปหักในกำไรต่อออเดอร์ (เฉพาะติ๊ก "จ่ายค่าส่งเงินสดต้นทาง" — ถ้าขนส่งหักจากยอด COD ไม่ลง จะไปสะท้อนที่ส่วนต่างตอนเงินเข้าแทน)
- Flash คิด COD fee 2.5% และ NNP 3% ของยอด COD (แก้อัตราที่ `COD_FEE_RATE` ใน index.html): Flash พิมพ์ fee ในใบแต่ไม่พิมพ์ยอด COD → ฟอร์มคำนวณยอด COD = fee ÷ 2.5% / NNP พิมพ์ยอด COD (`***3,090`) + ค่าส่ง 500 แต่เก็บ fee 3% สดนอกใบ → ฟอร์มคำนวณ fee = COD × 3% และลงค่าใช้จ่ายรวม (ค่าส่ง + fee)
- รายชื่อขนส่งแก้ที่แท็บ ตั้งค่า คอลัมน์ K
- ด่านก่อนบันทึก COD: เลขพัสดุรูปแบบถูก (Flash ขึ้น TH / NNP ขึ้น OT), ต้องมีชื่อผู้รับ (ไม่ใช่ Cash/ชื่อเรา), เบอร์ไม่ใช่ของเรา, ยอด COD 100–200,000, ค่าส่ง 0 แต่ติ๊กจ่ายสด → ถาม, สรุปให้ยืนยันก่อนบันทึก (เตือนถ้ามีรูปเดียว)
- กันซ้ำด้วยเลขพัสดุ

3. **📦 ค่าส่ง + ค่าธรรมเนียม COD** (แท็บ COD คอลัมน์ G/H/I): รายจ่ายจริงทั้งจ่ายสดต้นทางและที่ขนส่งหักจากยอด COD · แยกตามขนส่ง · แถวค่าส่ง COD ที่ระบบลงในแท็บค่าใช้จ่าย (หมายเหตุขึ้นต้น COD) ถูกตัดออกจากส่วนค่าใช้จ่าย กันนับซ้ำ
แท็บ **💰 รายรับ** (`?view=inc`): จากแท็บ ขาย ที่จดผ่านไลน์ แยก 3 กลุ่ม **ขาย COD** (หมายเหตุขึ้นต้น COD) / **ขายส่ง** (ช่องทาง ขายส่ง) / **โอน FB-LINE** · ยอดรวม + เงินเข้าแล้ว/ค้าง · ลูกค้าที่ซื้อมากสุด · รายการ (แถวเหลือง = ยังไม่ได้เงิน) · **📦 ติดตามเงิน COD** (KPI ค้างรับทุกเดือน + ตารางเงินเข้า/ค้าง) · **ไม่รวม Shopee/TikTok/Lazada** (ระบบแยก)

## คอลัมน์ที่เขียน
- **ค่าใช้จ่าย**: A วันที่ B ธุรกิจ C ประเภท D รายละเอียด E ยอด F มีใบกำกับ · I ผู้ขาย J อ้างอิงออเดอร์ K หมายเหตุ L เลขที่ใบกำกับ M เลขผู้เสียภาษี N รูปใบเสร็จ O ซื้อจาก
- **COD**: A วันที่ส่ง B ขนส่ง C เลขพัสดุ D ลูกค้า E สินค้า F ยอด COD G ค่าส่ง H COD fee I VAT · J รวมจ่าย (สูตร) · K อ้างอิง L เงินเข้าแล้ว M วันที่เงินเข้า N ยอดโอนเข้า · O ส่วนต่าง (สูตร) · P รูป Q หมายเหตุ R ผู้บันทึก
- **ขาย** (จาก COD): A–I ค่า, M และ S เป็นสูตรรายแถวอ้างแท็บ COD, O = 0, T หมายเหตุ, U เบอร์, V จังหวัด; (จาก ขาย): A–I, L, M, O, S, T, U, V
- **COD**: เพิ่ม S เบอร์โทร T จังหวัด (สรุปย้ายไป W1:X5)
- **สินค้า**: A รหัส B ประเภท C ยี่ห้อ D รุ่น E ขนาด F PCD G ออฟ H สี I ชื่อเต็ม · J คงเหลือ* K ต้นทุนเฉลี่ย* (สูตร MAP) · L หมายเหตุ M วันที่สร้าง
- **สต๊อกเคลื่อนไหว**: A วันที่ B รายการ C รหัส D ชื่อ E DOT (text) F จำนวน (+/−) G ต้นทุน/ชิ้น · H มูลค่า* (ARRAYFORMULA) · I เหตุผล J คู่ค้า K เลขบิล/ออเดอร์ L เลขพัสดุ M สภาพ N ที่เก็บ O รูป P ผู้บันทึก Q หมายเหตุ R เวลาบันทึก
- **ซื้อ**: A วันที่ B ธุรกิจ C ซัพพลายเออร์ D สินค้า E จำนวน F ยอดรวม G มีใบกำกับ · J เลขที่ใบกำกับ K ขนส่งเข้า L อ้างอิงออเดอร์ M หมายเหตุ N รูปใบเสร็จ O เลขผู้เสียภาษี P ซื้อจาก Q ใบกำกับตัวจริงรับแล้ว ☐

## แก้ไข / อัปเดต
- **แก้หน้าฟอร์ม** → แก้ `account/index.html` (อัปเดต `PAGE_VERSION` ด้วย) → push → รอ 1–2 นาที · ท้ายหน้าฟอร์มแสดง "เวอร์ชันหน้า" ไว้เช็คว่าโหลดหน้าใหม่แล้ว ถ้ายังเก่า เปิด `https://liff.line.me/2012109669-kGPX1UtI?v=<อะไรก็ได้>`
- **แก้หลังบ้าน** → แก้ `Code.gs` ใน Apps Script → บันทึก → **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (ไม่ทำ = โค้ดเก่ายังทำงาน) URL เดิม
- **เปลี่ยนชีท/โฟลเดอร์** → แก้ `SHEET_ID` / `FOLDER_ID` บนสุดของ Code.gs → Deploy ใหม่
- **รุ่น AI** → `GEMINI_PREFER` บนสุดของ Code.gs คือลำดับที่อยากใช้ ระบบดึงรายชื่อรุ่นที่คีย์ใช้ได้จริงจาก Google (cache 6 ชม.) แล้วจับคู่ ถ้ารุ่นแรกล้น (503/429) ไปรุ่นถัดไปเอง รุ่นที่ใช้ได้ล่าสุดอยู่ใน Script property `GEMINI_MODEL_OK`
- รายการ dropdown (ธุรกิจ/ประเภท/ซัพพลายเออร์) ดึงจากแท็บ `ตั้งค่า` ของชีท แก้ที่ชีทได้เลย

## 🗃 สต๊อกยาง/ล้อ (เพิ่ม 2026-11-06)
ปุ่ม **🗃 สต๊อกยาง/ล้อ** ในหน้าแรก (ทุกคนใช้ได้) → 4 โหมด · actions `stockList`, `stockSave` · AI `read` type `sidewall` / `stockbill` / `label`

| โหมด | ใช้ตอน | ทำอะไร |
|---|---|---|
| 🔢 นับตั้งต้น | นับของจริงครั้งแรก | จัดยางรุ่น/ขนาด/ปีเดียวกันเป็นกอง → 📷 ถ่ายแก้มยาง 1 เส้น (AI อ่านยี่ห้อ รุ่น ขนาด **DOT**) + ใส่จำนวน · ➕ เพิ่มกองได้หลายกองในครั้งเดียว |
| 📥 รับเข้า | ซื้อเก็บสต๊อก / ลูกค้าคืนล้อ | 📄 ถ่ายบิล → AI อ่านรายการ จำนวน ราคา → ถ่ายแก้มยางแต่ละรุ่นเพื่อใส่ DOT · ติ๊ก **ลงแท็บซื้อด้วย** = ไม่ต้องกด 🛞 ซื้อของมาขายซ้ำ (บิลที่มีในแท็บซื้อแล้วไม่ลงซ้ำ) |
| 📤 ตัดออก | ขายออนไลน์/COD/ขายส่ง/เคลม | 🏷 ถ่ายใบปะหน้า → AI อ่านเลขออเดอร์ เลขพัสดุ สินค้า จำนวน (ชุด 4 เส้น = 4) → จับคู่รหัส (SKU ตรง > ขนาด+ยี่ห้อ+รุ่น) → **DOT เก่าออกก่อน** แบ่งล็อตให้เอง · เลือกจากสต๊อกเองได้ |
| 🔍 ดูสต๊อก | ลูกค้าถาม / เช็คของ | ค้นหา ยี่ห้อ/ขนาด/รหัส (เช่น 225/50R18) · แยกปี DOT · แดง = ยางผลิตเกิน 2 ปี หรือติดลบ |

**รหัสสินค้า** (สร้างอัตโนมัติ) = **ยี่ห้อ 2 ตัว + รุ่น 2 ตัว + เบอร์** ติดกัน ไม่มีขีด
- ยาง: ATLANDER AX88 225/55R18 = `ATAX2255518` · ไม่มีรุ่น → ยี่ห้อ 4 ตัวแรก + เบอร์ DEESTONE 265/65R17 = `DEES2656517`
- ล้อ: ยี่ห้อ2 + รุ่น2 + ขอบ + กว้าง×10 + PCD + สี → KAYS K12 18x8.5 5x114.3 ดำ = `KAK118855114BK` (สี: BK ดำ, MBK ดำด้าน, GBK ดำเงา, SV เงิน, TI ไทเท, BZ บรอนซ์, GM กันเมทัล, WH ขาว, GD ทอง, PL ขัดเงา, CR โครม)
- ชนกัน (คนละสินค้าแต่รหัสเหมือน): ล้อต่างแค่ออฟ → เติม ET (`KAK118855114BK40`) · อื่นๆ → รุ่น 3 ตัว (`ATAX82255018`) → 4 ตัว → `-2`, `-3`
- ปี DOT **ไม่อยู่ในรหัส** (ช่อง E แยก) → ใช้รหัสเป็น **SKU บน Shopee/TikTok** ได้ตลอด
- สินค้าเดียวกัน = ประเภท+ยี่ห้อ+รุ่น+ขนาด(+PCD/ET/สี) เหมือนกัน (ไม่สนตัวพิมพ์/ช่องว่าง/ขีด) → ใช้รหัสเดิม
- ฟังก์ชันสร้างรหัสมี 2 ที่: `Code.gs` (ตัวจริง) และ `index.html` (แสดงตัวอย่าง) — แก้ที่หนึ่งต้องก๊อปไปอีกที่

**แท็บในชีทบัญชี** (สีเขียวอมฟ้า): `สต๊อกคงเหลือ` (สูตร LET/QUERY ที่ A6 — ห้ามพิมพ์ · รหัส×DOT คงเหลือ ต้นทุนเฉลี่ย มูลค่า เก็บมากี่วัน · ส้ม >90 วัน แดง >180 วัน/ยางเกิน 2 ปี) · `สินค้า` (แก้ชื่อ/รุ่นได้ แต่**ห้ามแก้รหัส**ถ้ามีการเคลื่อนไหวแล้ว) · `สต๊อกเคลื่อนไหว` (บันทึกทุกครั้ง — แก้ผิดให้เพิ่มแถว ปรับยอด แทนการลบ)
- ต้นทุนเฉลี่ย = เฉพาะแถวรับเข้าที่ใส่ราคา (นับตั้งต้นไม่ใส่ราคาได้ ไม่ดึงค่าเฉลี่ยลง) · ราคา = รวม VAT ตามบิลซัพพลายเออร์
- กันซ้ำ: ตัดออก = เลขออเดอร์/เลขพัสดุเดิม · รับเข้า = เลขบิลเดิม · DOT ต้องเป็น WWYY สัปดาห์ 01–53
- ตัดเกินยอด → บันทึกได้ แต่เตือน + ยอดติดลบ (แดง) ให้ไปเช็ค
