## วิธีใช้
1. กดปุ่ม 🧾 จดบัญชี ในไลน์
2. เลือก **ค่าใช้จ่าย** / **ซื้อยาง/ล้อ** / **ส่ง COD** → ถ่ายรูปใบเสร็จ
3. รอ AI อ่าน 3–5 วิ → ตรวจยอด/วันที่/ติ๊ก "มีใบกำกับภาษี" → บันทึก
4. ได้ข้อความสรุปในแชท + ลิงก์รูป / กด "จดใบต่อไป" ได้เลย

กติกาที่ฝังไว้
- ค่าน้ำมัน → ติ๊ก "มีใบกำกับ" ออกอัตโนมัติ (เคลม VAT ไม่ได้)
- กันซ้ำ (ปฏิเสธเลย ไม่ถาม): เลขที่ใบกำกับซ้ำในแท็บใดก็ได้ หรือ วันที่+ผู้ขาย+ยอดเท่ากัน → แจ้งแถวที่ซ้ำ ไม่บันทึก ไม่เก็บรูป
- ไม่มี GEMINI_API_KEY / เกินโควตา → ยังใช้ได้ แค่กรอกเอง
- คอลัมน์สูตร (ฐานภาษี/VAT) ไม่ถูกเขียนทับ — ชีทคำนวณเอง → ขึ้นแท็บ **รายงานภาษีซื้อ** อัตโนมัติ

### 📦 ส่ง COD (ใบเสร็จ Flash / ใบปะหน้า NNP ฯลฯ)
1 ใบ → เขียน 3 ที่ ผูกกันด้วย **เลขพัสดุ**:
- แท็บ **COD** (ทะเบียนพัสดุ): วันที่ ขนส่ง เลขพัสดุ ลูกค้า ยอด COD ค่าส่ง COD fee VAT · ☐ **เงินเข้าแล้ว** + วันที่/ยอดที่โอนเข้า (คุณติ๊กเองเมื่อขนส่งโอน) · มุมขวาบนสรุป COD ค้างรับ
- แท็บ **ขาย**: แถวขาย ช่องทาง Facebook (หรือที่เลือก) เลขออเดอร์ = เลขพัสดุ ยอด = COD ไม่ออกใบกำกับ · ช่อง "ยอดเงินเข้าจริง" และ "รับเงินแล้ว" เป็นสูตรดึงจากแท็บ COD อัตโนมัติ
- แท็บ **ค่าใช้จ่าย**: ค่าส่ง+ธรรมเนียม ประเภท Lalamove/ค่าส่งสินค้า อ้างอิงเลขพัสดุ → ไปหักในกำไรต่อออเดอร์ (เฉพาะติ๊ก "จ่ายค่าส่งเงินสดต้นทาง" — ถ้าขนส่งหักจากยอด COD ไม่ลง จะไปสะท้อนที่ส่วนต่างตอนเงินเข้าแทน)
- Flash คิด COD fee 2.5% และ NNP 3% ของยอด COD (แก้อัตราที่ `COD_FEE_RATE` ใน index.html): Flash พิมพ์ fee ในใบแต่ไม่พิมพ์ยอด COD → ฟอร์มคำนวณยอด COD = fee ÷ 2.5% / NNP พิมพ์ยอด COD (`***3,090`) + ค่าส่ง 500 แต่เก็บ fee 3% สดนอกใบ → ฟอร์มคำนวณ fee = COD × 3% และลงค่าใช้จ่ายรวม (ค่าส่ง + fee)
- รายชื่อขนส่งแก้ที่แท็บ ตั้งค่า คอลัมน์ K
- กันซ้ำด้วยเลขพัสดุ

## คอลัมน์ที่เขียน
- **ค่าใช้จ่าย**: A วันที่ B ธุรกิจ C ประเภท D รายละเอียด E ยอด F มีใบกำกับ · I ผู้ขาย J อ้างอิงออเดอร์ K หมายเหตุ L เลขที่ใบกำกับ M เลขผู้เสียภาษี N รูปใบเสร็จ
- **COD**: A วันที่ส่ง B ขนส่ง C เลขพัสดุ D ลูกค้า E สินค้า F ยอด COD G ค่าส่ง H COD fee I VAT · J รวมจ่าย (สูตร) · K อ้างอิง L เงินเข้าแล้ว M วันที่เงินเข้า N ยอดโอนเข้า · O ส่วนต่าง (สูตร) · P รูป Q หมายเหตุ R ผู้บันทึก
- **ขาย** (จาก COD): A–I ค่า, M และ S เป็นสูตรรายแถวอ้างแท็บ COD, O = 0, T หมายเหตุ
- **ซื้อ**: A วันที่ B ธุรกิจ C ซัพพลายเออร์ D สินค้า E จำนวน F ยอดรวม G มีใบกำกับ · J เลขที่ใบกำกับ K ขนส่งเข้า L อ้างอิงออเดอร์ M หมายเหตุ N รูปใบเสร็จ O เลขผู้เสียภาษี

## แก้ไข / อัปเดต
- **แก้หน้าฟอร์ม** → แก้ `account/index.html` → upload ทับใน GitHub → รอ 1–2 นาที
- **แก้หลังบ้าน** → แก้ `Code.gs` ใน Apps Script → บันทึก → **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (ไม่ทำ = โค้ดเก่ายังทำงาน) URL เดิม
- **เปลี่ยนชีท/โฟลเดอร์** → แก้ `SHEET_ID` / `FOLDER_ID` บนสุดของ Code.gs → Deploy ใหม่
- **รุ่น AI** → `GEMINI_PREFER` บนสุดของ Code.gs คือลำดับที่อยากใช้ ระบบดึงรายชื่อรุ่นที่คีย์ใช้ได้จริงจาก Google (cache 6 ชม.) แล้วจับคู่ ถ้ารุ่นแรกล้น (503/429) ไปรุ่นถัดไปเอง รุ่นที่ใช้ได้ล่าสุดอยู่ใน Script property `GEMINI_MODEL_OK`
- รายการ dropdown (ธุรกิจ/ประเภท/ซัพพลายเออร์) ดึงจากแท็บ `ตั้งค่า` ของชีท แก้ที่ชีทได้เลย
